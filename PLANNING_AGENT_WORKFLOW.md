# Planning Agent Workflow — Stale / Overlapping Task Audit

**Applies To**: Any agent performing an explicitly assigned stale or overlapping task audit  
**Purpose**: Short, generic procedure for targeted audit work

---

## Procedure

### 1. Confirm the assignment

Confirm the audited task and the specific question Tracy wants answered. Do not broaden scope beyond the assignment.

### 2. Inspect relevant context

Use available access to inspect:
- The audited task file
- Relevant current code, related tasks, review entries, and prior decisions
- Any overlapping or competing work

### 3. Assess readiness and unknowns

Check listed dependencies against current evidence when assessing readiness. Identify unknowns without inventing conclusions. Note what you verified vs. what remains unconfirmed.

### 4. Save one concise audit report

Save to the task/project output convention, or `summaries/` by default. Include:
- Task reference
- What remains relevant, completed, obsolete, or overlapping
- Evidence and dependency findings
- Recommended disposition: keep, targeted correction, hold, close, or consolidate
- Any specific decision needed from Tracy

### 5. Report briefly in chat

State the outcome and artifact location. Do not paste the full report.

## Do Not

- Modify, move, close, or dispatch the audited task unless that action is explicitly authorized
- Invent conclusions about dependencies or readiness
- Expand scope beyond the assigned question
