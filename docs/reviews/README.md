# Review Documentation

This folder contains the supporting procedures and dispatch materials for review work. The root `REVIEW_AGENT_GUIDE.md` remains the governing authority for reviewer independence, draft-task review requirements, evidence standards, dispositions, and human approval.

## Documents

| Document | Use |
|---|---|
| [Reviewer Access and Package Guide](REVIEWER_ACCESS_GUIDE.md) | Choose instructions from the actual session's repository/local/supplied-file access; optional ZIP packaging for reviewers without repository access. |
| [Draft Review Prompt Template](DRAFT_REVIEW_PROMPT_TEMPLATE.md) | Prepare the standard one-task draft review prompt and select the matching access block. |
| [Review Agent Workflow](REVIEW_AGENT_WORKFLOW.md) | General review-session procedure and concise review artifact expectations. |
| [Review Report Template](REVIEW_REPORT_TEMPLATE.md) | Reusable report structure for general/implementation reviews. |

## Authority and scope

- The root `REVIEW_AGENT_GUIDE.md` is authoritative. This folder does not replace or duplicate its review rules.
- `TASK_TEMPLATE.md` remains at the repository root because task creators use it directly and frequently.
- Draft-task reviews retain the existing three-file evidence minimum and GO / REVISE / STOP dispositions. The prompt is pasted into chat, not uploaded.
- ZIP is an optional transport for supplied-package-only reviewers, not a mandatory step or a new review workflow.
- Existing human approval, task lifecycle, dispatch, and commit/push gates are unchanged.
