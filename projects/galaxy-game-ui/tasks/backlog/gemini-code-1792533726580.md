# TASK SPECIFICATION: Galaxy Game UI Prototype (Rails 8)

## 1. Project Goal & Design Boundaries
Build a lightweight, standalone UI prototype for **Galaxy Game** using **Rails 8** and **Tailwind CSS**.
* **Constraint 1 (No Backend):** NO database models, migrations, or game engine workers. All data must be mocked in-memory within controllers, helpers, or static JSON structures.
* **Constraint 2 (Design vs. Domain):** Locate the reference Python dashboard at `[INSERT_CORRECT_PATH_HERE]`. **Borrow ONLY visual aesthetics, CSS styling, glassmorphic UI patterns, and network node/route rendering logic** (similar to EVE jump-gate maps). Do NOT copy EVE gameplay mechanics. All domain logic, terminology, and data structures must strictly match **Galaxy Game** specifications (AI Manager, PVEs, EAP, Wormhole stations).
* **Future Migration:** This code will serve as the frontend view layer that gets cleaned up and migrated into the main Galaxy Game Rails 8 application later.

## 2. Tech Stack & Setup Requirements
* **Framework:** Ruby on Rails 8 (`rails new galaxy_ui_prototype --css tailwind`)
* **Styling:** Tailwind CSS (matched to the dark sci-fi aesthetic extracted from reference assets)
* **Frontend Logic:** Hotwire (Turbo + Stimulus JS) for local client-side interaction mocks
* **Asset Pipeline:** Importmaps / Propshaft (Rails 8 defaults)

## 3. Core Functional Requirements

### Feature 1: Player Command Center (`/dashboard`)
Provide an operational view for active players monitoring fleets, extraction, and local markets.

* **System Status Header:**
  * Displays active system name (e.g., `ANTOLLARE III`), security level, local Earth Anchor Price (EAP) metric, and player ISK/GCC balance.
* **Active Sector Units Panel:**
  * Card list showing Galaxy Game units (e.g., *PVE Array-01* [Planetary Volatiles Extractor] extracting volatiles, *Heavy Transport Tug Alpha* in transit).
  * Status badges: Harvesting, In Transit, Idle, Docked.
* **Local Bay Inventory Visualizer:**
  * Grid showing resource stocks: Compressed Blue Ice, Oxygen Isotopes, Heavy Water, Exotic Matter (EM).
  * Visual progress/fill bars per resource type.
* **Market Quick-Panel:**
  * High-density table listing commodity lowest sell / highest buy spreads (Nitrogen, Cthonic Attar, Structural I-Beams).

---

### Feature 2: Wormhole Network & Transit Hub (`/wormholes`)
Model system connection graphs and transit routes (leveraging network node rendering styles inspired by the reference dashboard).

* **Wormhole Node Map:**
  * Graphical or high-density list representation of connected systems, displaying natural wormholes vs. artificial wormhole stations.
  * Node indicators showing mass stability, decay timers, and Exotic Matter (EM) harvesting potential.
* **Route & Transit Planner:**
  * Jump-route readout mapping system hops (e.g., `Antollare III ➔ Enedore ➔ Jita Hub`).
  * Unit mass / size restrictions visualizer for wormhole passage.

---

### Feature 3: Admin Telemetry & Control Panel (`/admin`)
Provide a supervisory dashboard for system inspection, simulation tick feedback, and market overrides.

* **AI Manager Status:**
  * Displays active AI directives (e.g., *Alpha Centauri Expansion*, *Wormhole Node Scanning*).
  * Mock action buttons: `Force Rebalance Tick`, `Trigger Natural Wormhole Event`.
* **Economic Indices:**
  * Global EAP baseline display.
  * System tax variables display: SCC Surcharge (0.5%), Broker Fee (0.3%), Sales Tax (3.37%).
* **Sim Engine Event Log:**
  * Real-time scrolling feed mock showing tick updates, extraction events, and trade execution logs.
