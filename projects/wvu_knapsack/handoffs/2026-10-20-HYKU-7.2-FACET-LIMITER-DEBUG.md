## Problem Statement
Facet limiting is working on main/digitalhistory.lib.wvu.edu (shows 5 items + "more »"), but **failing on feature/hyku-v7.2.0-upgrade/hykudev** (shows 10 items).

### Visible Symptoms
- **hykudev (7.2)**: People Represented, Location facets show ~10 items before "more »"
- **main (7.1.3)**: Same facets show exactly 5 items + "more »"
- **Date Created range facet**: WORKS on 7.2 (Praneeth's code), proving date_created_sim can be limited

### Why This Matters
- We upgraded to 7.2 specifically to test new features before production
- If facet limiting doesn't work on 7.2, we can't deploy with confidence
- Need to understand if it's a 7.2 regression or our implementation
