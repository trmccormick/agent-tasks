# QWEN AGENT PROMPT — Hyku 7.2.0 Root Cause Investigation

## Task: Investigate Why Hyku 7.2.0 Has Empty Search Results

You are investigating a critical bug: **Hyku 7.2.0 upgrade breaks search functionality (returns empty results)**.

**Current State:**
- hykudev v7.1.3 is running and stable
- Records exist in Solr (4000+ documents visible in index)
- Facets display with counts (proving Solr has data)
- BUT: Search queries return 0 results (empty pane)
- Fresh snapshot taken (v7.1.3 baseline)

**Working Theory:**
The Valkyrie indexer (v7.2.0 component) writes documents to one Solr collection (possibly "uuid"), but the search query builder queries from a different collection (likely "hydra-production"). This causes a collection mismatch: data exists in Solr but searches query the wrong collection.

```bash

# Check any other collections that exist

```
**Document:** Doc counts per collection. Expected: one collection has 4000+ docs, others have 0.

**Success Criteria:**
- If `uuid` has docs and `hydra-production` has 0 → collection mismatch **CONFIRMED**
- If both have docs or pattern is different → collection mismatch **DIFFERENT THAN EXPECTED** (report back)
