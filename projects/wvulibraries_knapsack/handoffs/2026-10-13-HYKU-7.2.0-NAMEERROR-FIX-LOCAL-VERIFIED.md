## What Was Accomplished

### Fix Implemented
**File:** `config/initializers/zzz_temporary_hyku_version_override.rb`

**Problem:** Unconditional access to `Hyku::ORIGINAL_VERSION` and `Hyku::VERSION` on line 26, but these were only defined inside a conditional block (lines 13-24). When Hyku module wasn't loaded in time, boot crashed with:
```
NameError: uninitialized constant Hyku::ORIGINAL_VERSION
```

**Solution:** Wrapped constant access with `defined?()` guards, defaulting to `'N/A'`:
```ruby
original = defined?(Hyku::ORIGINAL_VERSION) ? Hyku::ORIGINAL_VERSION : 'N/A'
current  = defined?(Hyku::VERSION)         ? Hyku::VERSION         : 'N/A'
Rails.logger.info "[WVU Knapsack] Temporarily overriding Hyku VERSION from '#{original}' to '#{current}' (will be removed when samvera/hyku#3397 is resolved)"
```
