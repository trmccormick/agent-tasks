## Architectural Decisions (Locked September 11, 2026)

### Foundation CSV & Data Import
1. **Alumni Flag:** New `is_alumni` boolean column, mapped from PRIMARY CONSTITUENCY field ("Alumni" → true, "Individual" → false)
2. **Education History:** Store raw in jsonb (all 3 degree blocks preserved), display condensed format: "College Name (Year)"
   - Support up to 3 degrees per person (education_1, education_2, education_3 column groups)
   - Model method `education_history` returns array of strings for display
3. **CSV Export:** Include manual entries with source tracking (entry_source column shows "csv" or "manual")

### Manual Entry Form & Plus-One Household Linking
4. **Quick Intake Form:** Simple fields only (First Name, Last Name, Alumni checkbox, Waiver checkbox)
   - CRM ID left NULL for manual entries (generated by system)
   - entry_source tracked as "manual" vs "csv"
   - Appears in search/check-in workflow alongside CSV entries

5. **Plus-One Household Linking:** New feature for tracking family/household members
   - New `linked_record_id` column (foreign key to graduate_records) for parent-child relationships
   - When creating manual entry for household member: link to parent record via dropdown or smart lookup
   - PRIMARY_ADDRESSEE copied from parent to linked record (e.g., "Mr. Kevin Adrian and Mrs. Lisa M. Adrian")
   - Example: Lisa Adrian linked to Kevin Adrian (her spouse) with linked_record_id pointing to Kevin

6. **Smart Lookup with Confirmation (Optional Enhancement):** UX workflow for finding existing household members
   - User types "Lisa" → search finds her in Kevin Adrian's PRIMARY_ADDRESSEE field
   - Confirmation modal: "Is this you attached to Kevin Adrian (A968258)? Yes / No"
   - If "Yes": Preview screen shows pre-filled data (name, ZIP, alumni status, entry note)
   - All fields editable before final creation
   - Creates record with linked_record_id and entry_note showing source: "Household member of Kevin Adrian (A968258)"
   - Speed benefit: ~15 seconds vs 45-60 seconds with manual dropdown selection
   - If "No": Returns to blank form for manual entry
   - Fallback: Manual dropdown still works without smart lookup implementation
